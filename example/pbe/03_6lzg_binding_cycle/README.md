# 6LZG fixed-structure polar electrostatic binding cycle

The example solves the complex (chains A+B), receptor (chain A), and ligand
(chain B) with the same Poisson-Boltzmann protocol. TITAN reports the polar
solvation contribution and the intercomponent Coulomb term in
`pbe_binding_electrostatics.csv`.

This fixed-structure calculation is provided to exercise the software path. It
does not include conformational sampling, nonpolar terms, entropy, or a claim
about biological affinity.
